# Clean Reply Desk

> **Purpose:** This file defines the Clean Reply Desk offer, intended customer journey, current technology stack, pricing, compliance boundaries, revenue goal, and next steps.

## Overview

**What it is:** A done-for-you quote-reply and follow-up system for residential cleaning businesses, starting in Charlotte, NC.

**Goal:** Build a recurring service that helps residential cleaning businesses handle quote requests through a structured draft, approval, reply, and follow-up workflow.

## Customer journey and workflow

The documented workflow is:

1. **Quote request:** A customer submits the quote request form.
2. **Capture:** The request is recorded in Google Sheets.
3. **Draft reply:** A reply is drafted automatically from the owner's prices.
4. **Owner approval:** The owner reviews and approves the draft.
5. **Send:** The approved reply sends from Gmail.
6. **Follow-up:** The workflow can send up to 2 follow-ups.
7. **Weekly report:** A weekly report is produced.

**Approval boundary:** The owner approves every reply. An automatically generated draft is not permission to send a customer message.
